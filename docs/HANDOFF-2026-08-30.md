## Operating facts that will save you an hour

- **`npm run typecheck` runs BOTH tsconfigs.** A bare `tsc --noEmit` is blind to
  all of `api/`.
- **Never pipe a verification into `tail`/`head` before reading its exit code.**
- **`npm run validate` currently FAILS in a clean worktree** — `format:check`
  runs tree-wide and trips on untracked scratch another process leaves behind.
  This is why the pre-push hook cannot simply run it.
- **The pre-push hook derives its guard list from `package.json`.** A new
  `check:*` script is enforced the moment it is defined. `lint` is deliberately
  excused (measured 15 s; CI catches it) — and that exception has already let one
  error through, so the register is capped at two entries.
- **`scripts/codex-review-mr.sh <branch> [file]`** runs an independent-model
  review and **its exit code is the gate**. It reads the branch via `git show`,
  not the working tree — it used to read the worktree and was right only by luck.
- **Codex briefs: one file, two hypotheses, ~2 KB, `< /dev/null`.** Broad briefs
  die. The verdict sits after the LAST `codex` marker.
- **A red light is not a verified one.** Codex was wrong at least four times
  here — about a JSON consumer that does not exist, about a count change that is
  a provable no-op, about `AlertChannel` callers. Check before acting, and check
  before dismissing.
